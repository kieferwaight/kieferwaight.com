# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue. Send a concise report to [kiefer.waight@icloud.com](mailto:kiefer.waight@icloud.com) with reproduction steps, affected paths, and potential impact.

You should receive an acknowledgment within seven days. Confirmed issues will be evaluated, remediated where appropriate, and credited at the maintainer's discretion.

## Scope

This policy covers the source repository and its deployment configuration. Third-party services and dependencies should also be reported to their respective maintainers.
