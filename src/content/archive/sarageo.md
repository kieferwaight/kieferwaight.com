# SaraGEO

**Role:** Co-founder and Architect

I co-founded SaraGEO with Sean Narvasa and served as the platform's architect. The project was later handed over to Raf Collado and Sascha Mornell.

This founding and handover history is my first-person account. The original product deck provides a separate record of the platform's scope.

SaraGEO's September 2015 product introduction presents a collaborative mapping platform for combining geographic data, media, and live location information. The 12-slide deck provides a historical view of the product's intended capabilities. [View the original presentation](https://www.slideshare.net/slideshow/sarageo-mapping-platform/52729335).

## Mapping and data

The deck describes basemap choice, drawing tools, annotations, media attachments, and map layers. It also presents file and database imports with point, cluster, and heatmap visualizations.

## Location and collaboration

Mobile pin creation connects a photograph to a location and shared map. Other slides describe live location updates, visibility controls, role-based collaboration, comments, and messaging.

## Developer platform

A developer API slide presents REST endpoints for maps, data, location, and social features backed by a geospatial store. The following platform slide is marked unfinished, so the deck offers limited evidence of the underlying architecture.

The deck documents the historical product presentation. My role as co-founder and architect is recorded above; individual feature implementation details are not specified here.
