# Andersen Corp

**Role:** Senior Front End Developer
**Dates:** June 2023 - Present

This entry is a personal account of the role, not a third-party or archived record. There is no external source or press citation to link to; it is included here for a complete career history.

## What the work involved

Front-end development across Andersen's web properties using React and Next.js, with a headless JSS integration into Sitecore for content management. The work spanned multiple brand properties, each with its own component library and content workflow, deployed through a modern hosting stack on Vercel.

## What this role demonstrates

- Enterprise front-end delivery inside a large corporate ecosystem
- CMS integration and component-based development patterns
- Coordinating front-end work across multiple brand properties
- Adapting to an established operating environment and toolchain
