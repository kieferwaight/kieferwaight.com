# Kickback Apps LLC

**Role:** Lead Developer
**Dates:** January 2019 - December 2021

This entry is a personal account of the role, not a third-party or archived record. It records my responsibilities and engagement dates; the linked PrankDial project page adds external sources for the product history.

## What the work involved

Led development across Kickback Apps' product portfolio. This included the Bellhop app, built with React Native, React, AWS services, and a Node.js backend, and prankdial.com, maintained alongside its Express.js API. A substantial part of the PrankDial work involved programming Asterisk call trees and working on the call-flow logic behind its telephone interactions. The role also covered live video editing and audio merging workflows for recordings, and a migration to a stateless, serverless architecture that reduced AWS operating costs.

## Related project

[PrankDial: Asterisk call programming, web, and API development](/archive/prankdial/) expands the telephony, website, and API account with product context, descriptions of historical mobile screens, and a founder narrative.

## What this role demonstrates

- Operating a portfolio of consumer-facing products across web and mobile
- Asterisk call-tree programming for a consumer telephony product
- Cost-sensitive cloud engineering and infrastructure migration
- Media processing workflows (video editing, audio merging) in a product context
- Balancing product velocity with infrastructure discipline
